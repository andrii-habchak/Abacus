# Abacus — agent guide

Personal finance tracker. Native **macOS app first**, iOS app second. Single user.
This file is the entry point for any agent (or human) picking the work up. Read it,
then the docs below, before touching code.

## Read order

1. `docs/STATUS.md` — where the work stands right now, what is in flight, what is next.
2. `docs/REQUIREMENTS.md` — the tech assignment (TA): what the app must do.
3. `docs/PLAN.md` — the execution plan: phases, work packages, dependencies, who can run in parallel.
4. `docs/DECISIONS.md` — settled decisions and why. Do not re-open them without the user.
5. `docs/design/` — agreed screen prototypes (once they exist).

## Working rules

- **Keep the docs current.** Whoever finishes or pauses a work package updates
  `docs/STATUS.md` (and ticks it in `docs/PLAN.md`) in the same commit. A new decision
  goes into `docs/DECISIONS.md`. The goal: a fresh agent can resume from the docs alone.
- **One work package = one branch = one commit series.** Branch name `wp/<id>-<slug>`
  (e.g. `wp/A2-fx-rates`). Stay inside the files your package owns (listed in `PLAN.md`);
  if you must touch a shared file, say so in `STATUS.md`.
- **Commit after each finished work package / phase**, build + tests green first.
  Commit messages: short imperative title, bullet body, a `Verified:` line.
  **No AI attribution anywhere**: no co-author trailers, no assistant/tool names in commits, PRs, README or docs (owner rule).
- Git identity is per-repo (`andrii-habchak` / personal email) and the remote uses the
  SSH host alias `github-vigil` — never change these to the global/work identity.
- Do not invent requirements. Anything unclear goes to "Open questions" in
  `docs/REQUIREMENTS.md` and is asked of the owner.

## Build facts (this Mac)

- `xcode-select` points at CommandLineTools, so terminal builds need
  `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.
- Xcode project is generated by **xcodegen** (`/opt/homebrew/bin/xcodegen`) from
  `project.yml`; the generated `.xcodeproj` is committed.
- Exact build/test commands are added here once Phase 0 scaffolding lands.
