# Abacus

A personal finance tracker for macOS (iOS to follow): accounts in UAH, PLN, EUR and USD,
income / expense / transfer transactions, categories, a home dashboard (net worth,
monthly budget, monthly expenses), and CSV import from the Saldo iOS app.

Status: **planning**. See [`docs/STATUS.md`](docs/STATUS.md).
