# C32 — Rules editor: category kind, debt picker, help
State: done (awaiting merge)   ·   Branch: wp/C32-rules-editor   ·   Updated: 2026-10-30

Owner requirements (approved): kind select above the category picker, debt picker instead of a
free-text person, help text per action, hint under the pattern field. Stored fields unchanged
(`categoryID`, `debtPersonName`); no migration.

## Design

- **Kind.** `RuleDraft.categoryKind` (default Expense). `RulesModel.categoryOptions(kind:)` lists
  that kind only (A–Z, subcategories under their parent). `setCategoryKind` clears a chosen category
  of the other kind. Editing an existing rule takes the kind from its category. Validation rejects a
  category of the other kind ("Choose an expense/income category."). The page's category filter has
  Expense / Income sections (`categoryFilterSections`).
- **Matcher.** `RuleMatcher.actionApplies` already required `subject.kind == category.kind`;
  `RuleEffect` passes the row's kind (income / expense) — verified by tests, no change needed.
  Import passes the row's kind the same way.
- **Debt picker.** Existing debts A–Z (one per person) plus "+ New debt…" (name prompt, saved through
  `DebtRepository.save`, then picked; an existing person is just picked). The rule still stores
  `debtPersonName` = the picked debt's person name. Action label is now "Transfer to debt"; list text
  "Transfer to debt · <person>".
- **Stale debt.** A debt rule whose person has no debt any more (renamed or deleted):
  list row shows "Debt missing" (tooltip explains); the editor shows a warning, the picker reads
  "<name> (missing)", saving is blocked until a debt is chosen. At match time
  `RuleMatcher(…, debts:)` skips such a rule (the next rule gets its turn); import and
  `RuleEffect` pass the debt book. Without a book the matcher behaves as before.
  **Behaviour change:** before, a debt rule for a person without a debt created the debt on
  import / apply; now it is skipped (the debt must exist). Creating the virtual account per
  currency is unchanged.
- **Help text** under the action picker, one sentence each; "Not case sensitive; accents ignored"
  under the pattern field.
- **Tester:** removed in S3 (D56), nothing to change; the editor's "will change" count respects the
  kind through `RuleEffect`.
