# C4 — navigation (D42)

Branch `wp/C4-navigation`. TA v1.5: R-HOME-2 (budget edit button), R-HOME-3 (click-only
drill-down), R-HOME-4 (currency switch only where it applies).

## Done

- **Jump to Transactions without a click (R-HOME-3).** Root cause: the expenses donut used
  `.chartAngleSelection(value: $angle)` and `.onChange(of: angle)` called the drill-down. On macOS
  the angle selection follows the pointer (hover), so a pointer resting where the donut appears —
  at launch, or after ‹ › changes the month and the chart redraws under it — opened Transactions.
  Now the donut has no angle selection: a chart overlay tracks hover (highlight only: the slice
  grows, help text names the drill-down) and only a click on the ring (not the hole) calls
  `onPick`. Legend rows were already buttons.
- Other paths that set `app.section` were checked: sidebar selection, ⌘1…⌘9, the
  `-AbacusSection` launch option (only when passed), `showTransactions` (drill-down, event's and
  import's "Show transactions" buttons), a data-folder move (keeps the section). All are user
  actions; `pendingTransactionFilters` and `sectionAppeared` never change the section.
- **Budget card edit button (R-HOME-2).** Pencil in the card header ("Edit budget") →
  `AppModel.openBudget()` → Budget section. Only the header and a new `onEdit` property changed
  in `DashboardBudgetCard` (C6 owns the body).
- **Display-currency switch (R-HOME-4).** `AppSection.usesDisplayCurrency` (Dashboard,
  Transactions, Accounts, Events); `ShellToolbar` shows `DisplayCurrencyPicker` only there.
