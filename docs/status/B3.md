## Integration notes (for B1 / B4 / wiring)
- B1: keep one `TransactionsViewModel` alive (e.g. `@State` in the root) and route
  `AppSection.transactions` to `TransactionsView(model:displayCurrency:onSelect:onOpen:)`,
  passing the shell's display currency. The view sets the window title and adds the search
  field to the toolbar.
- Wiring: build the model with the store's repositories and the `RateTable` from
  `RateRefresher.updates()` (assign `model.converter` on each update), `refundsReduceSpending`
  from `SettingKey.refundsReduceSpending`; call `model.load()` again after accounts, categories
  or events change, `model.reload()` after a transaction is saved / deleted / imported.
  `RateRefresher.ensureRates(for:)` with the visible days (`model.content.days.map(\.day)`).
- B4: `onOpen` (double-click / Return) opens the editor; `onSelect` reports the highlighted row.
- Dashboard drill-down / event view: set `model.filters = .drillDown(category:month:)` or
  `.event(_:)`, then select the Transactions section.
