## Result

could be driven (no Accessibility permission), so everything that needs a click is listed under "Not checked".

## Bugs fixed

1. **Reconcile screen came up blank** (window content and sidebar missing, only the toolbar title) and the
   window followed the content's ideal height (~3000 pt tall). `ReconcileView` had no ideal size; Import sets
   one for the same reason. Fix: `.frame(minWidth: 0, idealWidth: 900, …, idealHeight: 600, …)` on the view.
   Commit `Reconcile: give the screen an ideal size…`. No unit test possible (layout); verified by in-app
   snapshots before/after (`reconcile-setup.png`, `reconcile-red.png`, `reconcile-green-dark.png`).
2. **Import › Needs review › Pending payments / Balance gaps** also showed the Decisions intro ("Rows the
   importer could not place confidently…") and "Nothing needs a decision in this file." under the check lists.
   Fix: the Decisions and category sections are skipped for those two sub-tabs
   (`App/macOS/Import/ImportOtherTabs.swift`). Commit `Import: Pending payments and Balance gaps sub-tabs…`.

## Differences from the prototype (`N6-reconcile.dc.html`)

1. Transactions filter: prototype has a segmented All / Cleared / Uncleared; the app has one menu whose
   label reads "Cleared" while the filter is All (ambiguous: looks like the filter is active).
2. Prototype has Mark cleared / Mark uncleared / Mark settled buttons beside the filter and a legend row
   (Cleared / Uncleared / Pending hold / Transfer cleared on one side); the app has them only in the row
   context menu (spec `R-CLR-4` says "button and context menu"). No legend.
3. Prototype footer for one account shows "Balance · Cleared · Uncleared"; the app footer shows only
   Income / Expenses / Net.
4. "Not reconciled" badge is not on the Accounts list rows (prototype has it; N6 note says on purpose);
   it is only in the account window.
5. Reconcile: the toolbar title and the page header both say "Reconcile · PKO Personal" (duplicate); the setup
   step is centred in a 700 pt column instead of left-aligned.
6. Done-step date reads "25.01.2026" while the figures elsewhere use "25 Jan 2026" style (cosmetic).
7. Not compared screen by screen (could not click to reach them): the add / edit forms inside Reconcile,
   the "Edit" form of a stale hold, the editor sheet.

## Not checked (no Accessibility permission, so no synthetic clicks / keys)

- Mark cleared / uncleared and the All / Cleared / Uncleared choice in the running app (filter menu state
  not exercised; the model is covered by `TransactionsViewModel` tests).
- Editor "Cleared" checkbox (one per transfer side) and the warning on editing a bank-confirmed row: no launch
  option opens the editor; covered by `EditorClearedTests`.
- Clicking in Reconcile (tick, Add transaction, Edit, Delete, Mark settled, Finish, correction path, cash
  count, drift note): covered by `ReconcileModelTests`; only the rendered states above were seen.
- Import clicks: sub-tab switching, ⌘ / ⇧ selection, bulk Keep / Mark settled / Delete, Leave / Remove,
  Edit of a hold, Undo import in History restoring cleared flags: covered by `ClearedImportUndoTests`,
  `ImportChecksTests`, `StaleHoldsTests`; the decided / committed states were reached by launch options.
- Esc / Return / Tab keyboard behaviour (Return is the default action of Finish via `.keyboardShortcut`;
  not exercised).
- Narrow-window Reconcile (700 pt): `-AbacusWindowWidth` did not change the snapshot window, so the layout
  at a small width was **not seen**. From the code: the three figure tiles are in an `HStack` with
  `maxWidth: .infinity` and row lines have no wrapping, so a narrow window may truncate payee text.
- Light and dark were both seen for Reconcile; Import and Transactions were captured light only
  (`-AbacusDark` did not apply to the Transactions capture).
- One account window capture (PKO Personal, first run, 3 s delay) showed an empty Name field with the title
  "PKO Personal" and "Enter a name."; not reproduced with ≥ 5 s delay or with another account (likely the
  sheet captured before the draft loaded). Worth one manual look.
