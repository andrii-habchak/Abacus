  both scenes; `AppCommands`: "Lock Abacus" (⌥⌘L), data commands disabled while locked.

  With `-AbacusPreviewData` alone the lock is off.
- Run on the built app: with `-AbacusLockTest`, the lock screen appears at launch and shows the
  "cancelled" state (screenshot checked).
