# C26 — Debt link on the account editor
State: done (awaiting merge)   ·   Branch: wp/C26-account-debt-link   ·   Updated: 2026-10-30

TA v1.9 `R-DEBT-17`. Owned: the account editor (sheet, `AccountsModel` editor part, draft, tests).
Lane C27 owns the account/category list views.

## Why "Revolut Anna" could not get a debt or become a debt (owner question 2)

Reading the code, not guessing:

- **The kind is not locked by transactions.** Only the *currency* is (`isCurrencyLocked`, R-ACC-1).
  The Kind picker was enabled for the account.
- **The picker did not offer "Debt (person)" to a bank account.** `ManageText.liabilityKinds(offeredFor:)`
  (C14, `7e38508`) lists the kind `.debt` only when the account *already has* that kind, because debts
  with people live on the Debts tab. A Bank account's picker therefore had Assets plus Credit card and
  Loan, no Debt: that is why bank → debt was impossible.
- **There was no way to link at all.** The account sheet had no debt field; linking an existing account
  was only possible from the Debts tab's edit dialog (C20), which the owner did not find.

## Decisions

1. **New "Debt" section in the account sheet** (new and existing accounts): a searchable list (None,
   every debt, "New debt…"). Shown only when the app wires a debt repository.
2. **Linking is the intended way** for Revolut Anna: it stays a Bank account (kind and therefore balance /
   net-worth treatment are unchanged); its transactions drive the debt through the link (R-DEBT-18).
3. **Role** is derived, not asked: kind "Debt (person)" = virtual, any other kind = external. Changing the
   kind of a linked account updates the role on Save.
4. **An account in another debt is moved, not refused.** The section says "Currently in <debt>. Saving
   moves it to <other>; an account is in one debt only." (or "removes it from that debt" for None) before
   Save, so the confirmation is the visible text plus pressing Save. The move is unlink + link; when the
   second step fails the old link is put back. (The repository's `accountLinkedElsewhere` error is never
   reached from the sheet.)
5. **New debt…** creates a debt by name (not counted in net worth, R-DEBT-21), then links. The name must
   be non-empty and not match an existing person (key match): the message tells to pick it from the list.
6. **The kind stays locked out of "Debt (person)" for non-debt accounts** (not changed). Converting a bank
   account to kind debt would silently change what the account is: it would turn into a liability in the
   account part of net worth and lose its statement semantics, while the real goal (its transactions feeding
   a person's balance) is met by linking. Linked accounts of any kind already count only through the debt
   (R-DEBT-18), so nothing is lost. A kind "Debt (person)" account can still be created from the debt dialog
   ("Create account"), and an existing debt-kind account keeps the option.
