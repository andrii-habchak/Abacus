# C34 — Category picker with search

Branch `wp/C34-category-picker`. Owner requirement: every category selector has a search by
category name; a parent that matches includes its children; applies all over the app.

## Done

- `AbacusFeatures/Shared/CategorySearch.swift` (pure, tested in `CategorySearchTests`):
  - `CategoryPickerItem<Value>`: row (value, title, optional button title, `isChild`, group
    heading `section`, `isArchived`). `CategoryPickerItem.items(from:kinds:)` builds rows from
    categories already in picker order and takes the kind filter (`kinds: Set<CategoryKind>`,
    for lanes C31/C32).
  - `CategorySearch.hits(_:query:isSelected:)` and `.groups(...)`. Folding is
    `RulePattern.normalized` (case, diacritics, whitespace collapsed). Empty query = all rows.
    A matching parent brings all its children; a child that matches alone is returned under its
    parent as a context row (`isContext`: still selectable, drawn dimmed). Order and groups are
    kept; archived rows are dropped unless `isSelected` is true for them.
- `App/macOS/Shell/CategoryPicker.swift`: `CategoryPicker(items:selection:noneTitle:placeholder:width:)`.
  Button with the current choice, popover with a focused search field, list, up/down/return,
  headings when there is more than one group, optional none row (`noneTitle`, hidden while
  searching). `selection` is `Binding<Value?>`.
- Swapped in: Rules editor and Rules page filter, Import Transactions tab and Review record
  picker ("(new)" rows kept; `.none` is the picker's none row), transaction editor (category
  and split lines incl. the refund group), budget "Category to add", Categories editor "Parent".
- Transactions filter Categories popover (multi-select with counts, not a single-select
  picker): a search field above the list using the same `CategorySearch`; the "Uncategorised"
  row is hidden while searching. Kept minimal for lane C33.

## Not verified

Not looked at in the running app: popover size and focus, keyboard navigation, button widths in
the import row and rules editor, dimmed context rows.

## Proposed requirement text

R-UI-CATSEARCH: Every category picker offers a search field (focused when it opens) that
matches category names ignoring case and diacritics. A parent that matches shows all its
subcategories; a subcategory that matches alone is shown under its parent. Picker order,
Expense/Income grouping and the hiding of archived categories are unchanged.
