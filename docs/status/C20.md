## Design

- **One sign helper** `DebtSign` (`AbacusFeatures/Debts/DebtSign.swift`): stored balance (positive =
  they owe me) -> display (they owe me = negative, red, "you lent"; I owe = positive, green, "you
  borrowed"; zero = "settled up"). Every Debts-tab and widget figure goes through it; stored data is
  never touched.
- **Cached derived figures** in `DebtsModel` (balances, converted summary, hints), recomputed on
  load / rate refresh / display-currency change only, so the view body does no ledger replay (S1).
- **Edit debt dialog** (`DebtDraft`): name, note, due date, "Count in net worth" (off for new),
  searchable multi-select of accounts (`accountChoices`), accounts in another debt disabled with that
  debt's name, "Create account" (virtual: currency, optional opening balance), opening balance per
  linked account. Save order: debt, unlink, link, opening balances (`AccountRepository.save`),
  virtual accounts.
- **Detail header**: "Edit debt", "Show transactions" (`DebtsModel.onShowTransactions`, default
  no-op, wired by the orchestrator), Mark settled / Reopen; no "Add currency".
- **Right-click** on a Debts-list row and on a widget person row: Edit, Show transactions, Mark
  settled / Reopen, Delete (confirmation).
- Breakdown per account (role, currency, balance, opening) and the two non-blocking hints.

## Interpretations (owner to confirm)
1. **Opening balance in the dialog uses the display sign** (negative = they owe me, as everywhere in the
   Debts tab); it is stored with the flipped sign on the account, so the Accounts page shows the stored
   sign of the same field.
2. Accounts to pick: every non-archived account (kinds mixed); "never my own" is not enforced. New
   links are `external`; an account already linked here keeps its role.
3. Widget menu: "Mark settled" is shown but disabled (widget rows always have a non-zero balance).
   Edit there opens the Debts tab with the dialog; no dialog on the dashboard.
4. Idle hint after 30 days; shown only for open debts (C19 calculator).
5. Record rows and totals "I lent / They repaid" text on manual records unchanged; only signs and colours flip.
6. Saving the dialog is several repository calls (debt, unlink, link, openings, new accounts), not one
   transaction; a failure midway leaves what was saved.
