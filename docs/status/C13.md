# C13 — dashboard widgets (R-HOME-6)

Branch `wp/C13-dashboard`. TA v1.6 `R-HOME-6`; D52.

## Done

- **Monthly income donut.** The expenses card is now generic: `DashboardDonutCard`
  (`App/macOS/Dashboard/DashboardExpensesCard.swift`) over `DashboardDonut` (was
  `DashboardExpenses`, kept as a typealias) with a `kind`. Same month selector, same click-only
  drill-down (hover only highlights, R-HOME-3). With "Refunds reduce spending" off the income
  donut has a grey "Refunds" slice, which does not drill down (like before). Selections are per
  donut (`selectedSlice`, `selectedIncomeSlice`).
- **Drill-down target.** `DashboardModel.select(_:)` returns `DashboardDrillDown.Target`
  (kind, category, month); the shell calls `TransactionFilters.drillDown(target)`. Income slices
  filter to type Income + category + month; "Uncategorised" income → Income without a category.
  Expense drill-downs are unchanged (a category alone; Uncategorised → Expense). One-line change
  in `App/macOS/Shell/RootView.swift`; `TransactionFilters.drillDown` gained a `kind` (default
  expense).
- **Income vs expenses** (`DashboardIncomeExpensesCard`, `DashboardIncomeExpenses`): twelve
  months ending at the selected month, an income and an expenses bar per month, net as a line,
  12-month totals in the header. New aggregate `Calc.incomeExpenseSeries` (AbacusDomain
  `Reporting.swift`): the same report entries as the donuts and list totals, each at its day's
  rate; missing rates are left out and reported (D27). Hover shows a month's figures under the
  chart. **Click on a month selects it in the month selector** (chosen: it never leaves the
  dashboard; months before the first transaction aren't clickable).
- **Reorder by drag and drop.** `DashboardWidget` (netWorth, budget, expenses, income,
  incomeVsExpenses, debts) and `DashboardLayout` (AbacusFeatures `DashboardLayout.swift`). Each
  widget has a grip at its top edge; dropping it on another widget puts it in that widget's
  place. Context menu: Move Earlier / Move Later / Reset Layout; a "Reset layout" button in the
  footer while the order isn't the default. Full width: net worth, income vs expenses, debts;
  half width: budget, expenses, income, two per row from 696 pt content width, one per row
  below; a half widget alone keeps half width. The month selector is now pinned above all
  widgets (it would otherwise move with whatever widget was first).
- **Persistence:** `SettingKey.dashboardLayout` = JSON array of ids. Unknown ids dropped,
  duplicates collapsed, widgets missing from the list appended in default order (new widgets show
  up); unreadable → default; a settings read failure never fails the dashboard.
- **Debts slot:** `DashboardView(..., debts: AnyView?)`, default nil → the Debts widget is hidden
  but keeps its place in the order. At merge: in `RootView` pass
  `debts: AnyView(<C14 debts widget view>)`.
- DEBUG: the dashboard honours `-AbacusWindowWidth/-AbacusWindowHeight` (narrow snapshots).
