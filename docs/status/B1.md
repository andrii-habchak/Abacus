# B1 — Shell, settings, rates
State: done (live on the app database)   ·   Branch: wp/B1-shell   ·   Updated: 2026-10-21

Built against the approved prototypes `docs/design/1-dashboard.dc.html` (shell) and
`docs/design/6-rates-settings.dc.html` (rates screen, Settings window). Rebased on `main` with
A1–A5, B2–B5 merged. Scope added by the orchestrator: live wiring of every built screen, the
editor, and "Load Sample Data".

## Done
- **App session** `AbacusFeatures/Shell/AppSession.swift`: one object for the window —
  `AppModel` (settings, rates screen, Settings window) plus one model per screen (Dashboard,
  Transactions, Accounts, Categories, Budget, Events, Rules) kept alive across section switches,
  and the transaction editor's dependencies. `live(database:)` uses the SQLite repositories (A5),
  `SQLiteBackup`, and one `RateRefresher(store: SQLiteRateStore, source:
  FallbackRateSource.standard())` (A2): auto-refresh flag from `SettingKey.ratesAutoRefresh`, cache
  loaded at launch, the launch fetch and `runDailySchedule()` in background tasks, every
  `updates()` snapshot fed to the Transactions and editor converters, `DashboardModel.refreshRates()`,
  `EventsModel.refreshRates()` and the rates screen. `preview()` runs everything on synthetic data.
  The app opens `AppSession.live(databasePath:)` on the `defaultDatabase` from `AppBootstrap`.
- **Shared app model** `AppModel`: section; display currency (R-HOME-4), "Refunds reduce category
  spending" (R-SET-3, also pushed to the list and the dashboard), "Update rates automatically"
  (R-SET-1, also passed to the refresher) — via `SettingsRepository`; toolbar "NBU rates · <day>"
  (R-FX-4); `editor` (`.new` from "New transaction"/⌘N, `.edit(id)` from a list row);
  `showTransactions(_:)` → `pendingTransactionFilters` + Transactions (dashboard drill-down,
  event "Show N transactions").
- **Main window** `App/macOS/Shell/`: sidebar (Overview / Manage, Settings… at the bottom),
  toolbar (rates-as-of label with an amber icon after a failed fetch, display-currency segmented
  control, "New transaction"). `SectionDetail` routes Dashboard, Transactions, Accounts,
  Categories, Budget, Events, Rules and Exchange rates; Import is the only placeholder (B6).
  Display currency passed to Dashboard, Transactions, Accounts, Events. After the editor saves or
  deletes, the list, the dashboard and the opened manage screens reload; switching to a section
  re-reads it if it was shown before. Commands: File › New Transaction ⌘N, View › sections
  ⌘1…⌘9, Refresh Rates ⌘R, Help › Load Sample Data; Settings ⌘,.
- **Load Sample Data** (`SampleData.loadIfEmpty`): seeds `PreviewData` accounts, categories,
  events, transactions and budget **only when the database has no account** — otherwise an alert
  explains it did nothing. Settings and rates are not seeded (real rates are fetched).
- **Exchange rates** (R-FX-2/4/5): `RatesModel` over `RateStore` + `RatesService`
  (`RefresherRatesService` over A2's refresher; `PreviewRatesService` for previews/tests) with
  A2's `RateTable` / `RatesOverview`: today's rates with "Show in", day change (a rounded 0.00% is
  flat), 30-day Swift Charts sparkline, NBU/Manual badge; updated label; Refresh rates; offline
  banner with Try again; manual rates list and add form (one day / from a day until changed).
- **Settings scene** (General / Rates / Data): display currency, refunds toggle with its changing
  explanation; auto-update toggle, source, manual-rate count; data folder (Show in Finder),
  Export backup… / Restore from backup… ("Replace all data with “…”?"), last export date. Restore
  reloads every screen.
- **Tests** (`AppModelTests`, `RatesModelTests`, `RefresherRatesServiceTests`, `AppSessionTests`;
  B1: 41) named with R-HOME-4, R-SET-1/2/3, R-FX-1/2/4/5, R-EVT-3 — live ones on in-memory
  databases with a stubbed rate source. Full `swift test`: 471 passed. App `BUILD SUCCEEDED`.
- **Previews** on preview data: main window (+ rates), sidebar, rates (+ offline), Settings,
  General tab.
- **Screenshots** `docs/status/B1-screens/` — the running app on a **temporary database seeded
  by Load Sample Data** with real NBU rates fetched at launch: `main-window(-dark)`,
  `transactions`, `accounts`, `events`, `import-placeholder`, `rates(-dark)`,
  `settings-general(-dark)`, `settings-rates`; on preview data: `rates-offline-preview`,
  `settings-data`. Taken in-app (debug only, `App/macOS/Shell/WindowSnapshot.swift`) because the
  terminal has no Screen Recording permission: Liquid Glass does not draw off-screen, so the
  sidebar pane, its selection and the selected toolbar segment are repainted plainly; traffic
  lights are missing, and the Settings… link in dark mode. Launch options (`AbacusApp.swift`):
  `-AbacusDatabasePath <file>`, `-AbacusLoadSampleData YES`, `-AbacusPreviewData YES`,
  `-AbacusOffline YES`, `-AbacusSection <section>`, `-AbacusOpenSettings general|rates|data`;
  snapshot: `-AbacusSnapshotDir <dir> -AbacusSnapshotName <name> [-AbacusDark YES]
  [-AbacusSnapshotDelay <s>]`.
