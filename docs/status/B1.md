## Blockers / contract-change requests (for the orchestrator)
- **`project.yml` synced folder is not on `main`.** STATUS/D23 say app sources are a synced
  folder, but `project.yml` still lists `App/macOS` as a plain source and the `.xcodeproj` has no
  synchronized group, so new files under `App/macOS/` do not build until the project is
  regenerated. I regenerated locally (`xcodegen generate`) to build and did **not** commit the
  `.xcodeproj`. On merge: land the synced folder or regenerate the project.
- **`SettingKey.lastBackupExport`** (ISO date) for "Last export: …". Interim: `LastExportStore`
  (`UserDefaults` key `lastBackupExport`, injected via `AppEnvironment`).
- **Data folder location** (R-SET-1 "Change…"): needs a store-side API to move/reopen the database
  and a location remembered outside the database (e.g. `UserDefaults` bookmark read by
  `AbacusDatabase.defaultURL()`). B1 calls `DataLocationService.moveDatabase(to:)`; only a preview
  implementation exists.
- **Wiring** (orchestrator, `App/macOS/AbacusApp.swift` builds `AppEnvironment.preview()` today):
  `AppEnvironment(settings: SQLiteSettingsRepository(db), rateStore: SQLiteRateStore(db),
  rates: RefresherRatesService(refresher:), backup: SQLiteBackup(db) /* add
  `extension SQLiteBackup: BackupService {}` */, dataLocation: <real impl>, lastExport:
  .userDefaults(), today: { Day(Date()) })`; one `RateRefresher(store:autoRefresh:)` with the flag
  from settings, `start()` on launch and `runDailySchedule()` in a task (R-FX-1). After a restore
  `AppModel.load()` reloads; other screens must reload too.
