# C11 — Transactions, events (Phase 3d, owner review of 1.1.0)

Branch `wp/C11-transactions-events`. TA v1.6: R-LIST-2, R-EVT-3, R-MGMT-4, R-MGMT-10, R-MGMT-11.

## Done
- **Page search (R-MGMT-11)**: Transactions drops the toolbar `.searchable`; `PageSearchField`
  sits full width above the filter bar. Events gets the same field above the list, filtering
  by name (case- and accent-insensitive, `EventsModel.search`); an empty result says so.
- **Filter bar layout**: chips sit in a wrapping flow layout (`TxnFlowLayout`); the type
  toggles are fixed-size with one-line labels, so they never break into "Expens e". When the
  row is too narrow the chips move to a second line; "Clear filters" and the sort button stay
  at the trailing edge of the first line. Checked at 1,280 and 1,000 pt.
- **Event "Show N transactions" bug**: `TransactionFilters.event` used the event's start/end
  as the date range, so the list hid tagged transactions outside those dates (a booking before
  the trip, a reimbursement or a transfer after it) and showed fewer rows than the N the event
  view counts (every tagged transaction, any date, any type). Now it opens with all dates, all
  types, and only the event filter; the type toggles combine with it. The squeezed type labels
  in the same screenshot were the layout bug above (long custom-date chip + event chip + Clear
  filters).
- **Event inspector**: Spent card (with category bars) right under the budget field; then
  colour, the auto-tag note, "Show N transactions"; a divider and Archive/Unarchive + Delete…
  (small, left-aligned, own row); Revert + Save changes (Cancel + Create for a new event) at
  the bottom-right (R-MGMT-10).
- **Archived event is read-only**: name, start, end, budget and currency are disabled with a
  note "Archived. Unarchive it to change the name, dates or budget."; the colour stays
  editable (cosmetic, shows on badges). The model enforces it too: saving an archived event
  writes only its colour.
- DEBUG-only launch options for UI checks: `-AbacusTransactionsEvent <name>`,
  `-AbacusTransactionsSearch <text>`, `-AbacusTransactionsTypes expense,income`,
  `-AbacusEventsSelect <name>`, `-AbacusEventsSearch <text>`, `-AbacusEventsEditBudget <text>`,
  `-AbacusWindowWidth <pt>` / `-AbacusWindowHeight <pt>`.
