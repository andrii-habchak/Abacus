  only open the list (see requests).
- The screen draws its own step bar under the window toolbar (title via `.navigationTitle`).

## Interpretations (flag to the owner if wrong)
- Review rows start undecided (the pipeline refuses to commit them); the suggestion is marked
  and "Use suggestions (N)" applies them all. The prototype showed defaults pre-ticked.
- Picking a different PKO target account rebuilds the preview and drops choices made so far.
- A file with nothing to do (re-import) disables Import ("Nothing new in this file.") instead of
  writing an empty batch.
- Target account choices: active accounts in the statement's currency (any kind).
