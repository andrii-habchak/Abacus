# QA-171 · N6 polish against the approved prototype

Branch `wp/QA-171-n6-polish`. Source list: `docs/status/QA-170.md` "Differences from the prototype".

## Changed

- **Item 1, filter label.** The Transactions cleared filter is now a segmented All / Cleared / Uncleared
  control (as in the prototype) instead of a menu whose label read "Cleared" while the filter was All.
- **Item 2, buttons and legend.** The filter bar has Mark cleared / Mark uncleared / Mark settled buttons,
  enabled by the selection (same rules as the context menu: `canMarkCleared`, `canMarkSettled`). A legend row
  above the footer explains the four marks (Cleared, Uncleared, Pending hold, Transfer cleared on one side).
- **Item 3, footer.** With exactly one account filtered, the footer shows
  "N transactions · Balance · Cleared · Uncleared" in the account's currency, over the whole history (not
  limited by the date filter). New `TransactionsViewModel.accountFigures` (balance = opening + all effects,
  cleared = opening + cleared non-pending effects, uncleared = difference). Income / Expenses / Net stay.
- **Item 5, Reconcile.** The page header no longer repeats the title (the window title keeps
  "Reconcile · <account>"); the header shows only "Last reconciled …". The setup step is left-aligned (still
  capped at 700 pt).
- Test: `TransactionsAccountFiguresTests` (figures only for one account; filter choices).
