# C3 — Import window height

Branch `wp/C3-import-height`. Owned path: `App/macOS/Import/` (Shell not touched).

## State: done

### Root cause

`ImportChooseFileStep` (in `ImportView.swift`) gave its description paragraph
`.fixedSize(horizontal: false, vertical: true)`. The window works out its minimum size by
measuring the content at a zero width. At that width the fixed-height paragraph wraps one glyph
per line, so its height became the window's minimum height (2,251 pt). Because the Import model
starts on this step, the leak happened even when a file was opened later.

How it was found (in-app snapshots on a temporary sample database, with the 2cf555b frame
removed):
- With the frame removed, the choose-file step and the review step both gave 2,251 pt.
- Hiding the History overlay made no difference (still 2,251 pt).
- Swapping the choose-file step for `Color.clear` gave 1,018 pt, the same as the Dashboard.
- Dropping the paragraph's vertical `fixedSize` gave 1,018 pt on both steps, even with the
  frame still removed. The paragraph still wraps normally.

### The "~1,018 pt vs 860 pt" gap is not an Import problem

On this Mac (1,728×1,117 pt screen) Dashboard, Accounts, Rules and Import all snapshot at
1,280×1,018 pt. The snapshot captures the whole window frame, so 1,018 pt is simply the default
window here. The 860 pt in `.defaultSize` is not the height the snapshot shows. After 2cf555b the
Import section already matched the Dashboard. What was left was the real leak above, hidden by
the 2cf555b frame.

### Changes (`App/macOS/Import/ImportView.swift`)

- Removed the vertical `fixedSize` from the choose-file paragraph. This is the fix.
- Kept the 2cf555b `.frame(minHeight: 0, idealHeight: 600, …)` as a guard and corrected its
  comment. The Done step, the PKO account prompt and the other review tabs can't be reached from
  launch options, so the guard stays there for them.
- DEBUG-only launch option `-AbacusImportFile <csv>` opens that file in the review step, so the
  review step can be snapshotted. Orchestrator: consider adding it to the launch-option list in
  STATUS "How to check the UI safely".
