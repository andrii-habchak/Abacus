# N2 — local MCP server `abacus-mcp`

Lane branch `wp/N2-mcp`. Owned: `AbacusKit/Sources/AbacusMCP/**`, `AbacusMCPTool/**`,
`Tests/AbacusMCPTests/**`, this file, the README MCP section.

## Decisions

- **No SDK dependency.** The official Swift MCP SDK would add a package dependency (plus its own
  transitive ones: logging, system, NIO-style async) for a surface Abacus barely uses. The server
  needs `initialize`, `ping`, `tools/list`, `tools/call` over newline-delimited stdio, which is
  about 150 lines (`Protocol/MCPServer.swift`). It speaks protocol versions 2025-06-18, 2025-03-26
  and 2024-11-05. If resources, prompts or progress are ever wanted, revisit.
- **Read-only connection.** `MCPDatabase.openReadOnly` opens SQLite with `readonly`; it never calls
  `AbacusDatabase.open`, so the server cannot migrate. A schema older than this build is an error
  at start ("open Abacus once"); a newer one is read with a warning on stderr.
- **Query layer** (`Queries/`): `AbacusQueries` reuses `Calc.*`, `SQLiteReportQueries` and the
  repositories, so figures match the app. Tools in `Tools/ReadTools.swift` only parse arguments and
  encode the DTO. A CLI can call `AbacusQueries` directly.
- **Privacy:** DTOs have no `iban` field; tests assert the IBAN never appears. Descriptions (payee,
  note) are returned. Search is capped at 200 rows and reports the total matched.

## Requests to the orchestrator

1. **`Package.swift`: add `"AbacusFX"` to the `AbacusMCP` target's dependencies.** The live rate
   table (`RateTable`) lives in AbacusFX. Until then `LiveRates.source` is `NoRates`: only
   same-currency amounts convert and everything else is listed under `unconverted`. After the
   dependency lands, replace `Queries/LiveRates.swift` body with:

   ```swift
   import AbacusFX
   public enum LiveRates {
     public static let source: RateSource = { database in
       let store = SQLiteRateStore(database: database)
       return RateTable(rates: try await store.latestRates() + /* history */, overrides: try await store.overrides())
     }
   }
   ```
   (history: `store.rates(from:to:)` over the earliest transaction day…today, as the app's rate
   service does; check `AbacusFeatures/Rates/RatesService.swift` for the exact loading.)
