# C21 — Transactions debt filter
State: done (awaiting merge)   ·   Branch: wp/C21-debt-filter   ·   Updated: 2026-10-30

`R-DEBT-22`. Builds on C19 (`DebtBook.links(of:)`).

## Behaviour

- Filter bar: a **Debts** chip (after Accounts, shown when the model has a debt repository) opens a
  searchable list of debts A–Z (name + "N accounts"). Ticking a debt selects all its linked accounts:
  they are ticked in the Accounts menu and shown as removable chips next to a removable debt chip.
- Un-ticking one account (menu or chip ×) keeps the debt and the other accounts. Un-ticking the debt
  removes exactly the account entries it added; accounts the user had selected independently stay.
- A selected debt with every account entry removed (or a debt without accounts) matches **nothing**
  (query is nil), not everything.
- "Show transactions" of a debt uses every date (like events). Clear filters resets debt and chips.
- Totals/summary follow the filtered rows (unchanged pipeline). The account set per debt is computed
  once in `loadDebtOptions()`; there are no per-row debt lookups. `book()` is read lazily (when the
  Debts popover opens, on `showTransactions(ofDebt:)`, or on `load()` when a debt filter is set).

## API

- `TransactionFilters`: `debtIDs`, `debtAccountIDs` (what each debt added), `.debt(_:accountIDs:)`,
  `addDebt`, `removeDebt`, `debtAddedAccountIDs`, `isDebtFiltered`; `toggleAccount` drops the entry
  from the debt's added set.
- `TransactionsViewModel` (additive, at the end of the class): `debtOptions`, `loadDebtOptions()`,
  `debtOptions(matching:)`, `toggleDebt`, `debtLabel`, `selectedDebts`, `debtAccountChips`,
  `removeAccountEntry`, `filters(showingDebt:)`, `offersDebtFilter`; `DebtFilterOption`.
- **Entry point for the Debts page:** `AppSession.showTransactions(ofDebt: Debt.ID) -> Task<Void, Never>`
  (`@discardableResult`). Switches `app.section` to Transactions with the debt filter via
  `app.showTransactions`. Wire C20's closure as `onShowTransactions: { session.showTransactions(ofDebt: $0) }`.
  Does nothing for an unknown debt.
