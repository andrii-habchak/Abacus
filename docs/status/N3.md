## 2. Headless `abacus-import` linking — done
The tool's pipeline had no refund / counterpart repositories, so nothing was ever offered. Now it
is wired like the wizard (`SQLiteRefundRepository`, `SQLiteTransferCounterpartRepository`) and,
as nobody can click "Accept", calls `ImportPreview.acceptingOffers()` before `acceptingDefaults()`:
it accepts every refund offer (same description + amount, C35) and every estimated-transfer offer
(C38), in file order, and prints `offers accepted: refunds N · estimated transfers completed M`
(counts only). Unchanged on purpose: a "Transfer to my account" review row whose amount on the other
account is unknown is still recorded by sign (`acceptingDefaults`) — picking a counterpart is a
user decision, not a default. Tests: `HeadlessOffersTests` (C35, C38). The tool's own wiring
is an executable and is covered only by the build plus these preview-level tests.
