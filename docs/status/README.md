# Work-package status notes

One file per work package: `docs/status/<WP>.md` (e.g. `A2.md`), created by the lane when it
starts and kept current. Template:

```markdown
# <WP> — <title>
State: in progress | blocked | done   ·   Branch: wp/<id>-<slug>   ·   Updated: YYYY-MM-DD

## Done
## Next
## Blockers / contract-change requests (for the orchestrator)
## Deferred
```
