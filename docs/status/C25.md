# C25 — Debts UI fixes
State: done (awaiting merge)   ·   Branch: wp/C25-debts-ui-fixes   ·   Updated: 2026-10-30

Owner findings on 1.4.0 (R-DEBT-21, D61). Owned: `AbacusFeatures/Debts/`, `App/macOS/Debts/`, their tests.

## Plan
- A: widget header = one "≈ total" debt sum (display currency, D61 sign/colour, "No rate" fallback).
- B: list and widget rows show one main figure (the person's total in the display currency); per-currency
  amounts only as a small caption without lent/borrowed labels, only when the debt has several currencies.
- C: edit debt sheet: fixed title, one scroll area, footer; "Linked accounts" section on top, then a
  searchable "Add accounts" picker; "Create account" in its own section.

## Findings
- Picker clipping: the account list had `.frame(maxHeight: 220)` and no scroll view of its own, so rows past
  the cap were cut off and unreachable. Accounts were not filtered by kind; archived ones are hidden unless linked.
- Create-account overlap: same cause (the capped list drew over the rows below).

## Interpretations (owner to confirm)
1. Secondary caption = the per-currency amounts joined by " · " in the display sign, shown only when the debt
   has more than one non-zero currency (a single-currency debt in a non-display currency shows only the converted figure).
2. The main figure carries "≈ " when a balance had to be converted.

## Done
- Widget: `DashboardDebts.total/totalText/isApproximate` (one sum of the people, nil = "No rate"); card shows
  "≈ total" / "Total" with it; "Open Debts" kept. `lentText/borrowedText` removed.
- Rows (list and widget): main figure = person total (`PersonRow.total`, `Person.totalText`), `secondaryText`
  caption via `DebtSign.caption` (more than one non-zero currency only). `convertedText` removed. The Debts-list
  header totals (You lent / You borrowed) were not in the findings and are unchanged.
- Dialog: fixed title, one ScrollView, fixed footer; sections Linked accounts (name, role, currency, opening,
  unlink), Add accounts (search, all non-archived free accounts, "In <debt>" disabled), Create account.
  Model: `linkedAccountRows`, `addableAccountChoices`.
- Tests (DebtsUITests, DebtsCurrencyTests): R-DEBT-21 total on widget and rows, caption rule, dialog lists.
- Gate: `swift test` green, app build succeeded. NOT checked visually (no screenshot taken); layout is unverified on screen.
