# C30 — Refund links
State: in progress   ·   Branch: wp/C30-refund-links   ·   Updated: 2026-10-30

Owner-approved design: a refund transaction is linked to the original expense so a returned
purchase cancels the expense in reports. Lane C31 works on the import wizard in parallel; this lane
keeps out of `AbacusImport/` and the import views.

## Design (as built)
- **Schema:** migration v15 adds `txns.refundOfID TEXT` (nullable, no foreign key, no constraint) and a
  partial index on it. Append-only, idempotent (column checked), existing rows stay NULL. `Txn.refundOfID`.
- **Rules:** only an expense with `isRefund` carries a link; the original is an expense that is not a
  refund, not a balance correction, not a debt leg. Many refunds per expense; the sum of the linked
  refunds converted to the original's currency (at each refund's date) may not exceed the original
  amount (`RefundError.exceedsOriginal(remainingMinor:currency:)`). Transfers and corrections are never refunds.
- **Category:** a linked refund stores the original's category in its own `categoryID`. The store keeps
  it in sync (`RefundLinks.repair`, called by the transaction save/delete, rule apply/rollback, import
  commit/undo and debt conversion write paths), so every calculator and SQL query keeps reading one
  column and nets that category without a join.
- **Reporting:** a linked refund always reduces the original category's spending (a negative expense),
  on the refund's own day and in its own account currency (converted at the refund's date like any
  amount), regardless of R-SET-3. Unlinked refunds follow R-SET-3. Places changed: `Calc.reportEntries`
  (donut, budget, events, income vs expenses, list totals all go through it), `SQLiteReportQueries.spending`
  (`FlowRow.isLinkedRefund`), `TxnTotals`, `TxnRepository.summary` (grouped by the link flag),
  `TxnListSummary.Main.isLinkedRefund`, `TransactionTotalsRule`. Net worth and balances do not look at the
  link (cash moves anyway).
- **Deleting the original** clears the link of its refunds (they keep their own category and become unlinked
  expense refunds again, R-SET-3 applies). Same repair when the original becomes a transfer, a debt leg or a
  refund.
- **Repository:** `RefundRepository` protocol (AbacusDomain) / `SQLiteRefundRepository` (AbacusStore):
  `linkRefund`, `unlinkRefund`, `refundCandidates(for:matching:limit:)`, `refundTargets(for:matching:limit:)`,
  `refundLinks(for:)` (two aggregate reads for a page of ids, no per-row query). Cross-currency uses a
  converter provider closure given to the repository.
